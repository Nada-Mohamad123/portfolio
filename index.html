About Me

I am a Backend Developer. I build the part of an application that users never see but depend on: the APIs, the authentication, the database and the connections between systems.

I work with Java and Spring Boot, Python and Flask, and ASP.NET Core, and store data in SQL Server and PostgreSQL. For larger systems I split the work into microservices and connect them with WSO2 API Gateway, Apache Kafka and WebSockets.

My projects include a banking back end, an online bookstore with secure login, and a real-time content-safety system. Several of them are packaged with Docker, so they run the same way on any machine.
